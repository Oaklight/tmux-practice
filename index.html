A config worth keeping

Put this in ~/.tmux.conf, then tmux source-file ~/.tmux.conf.

set -g mouse on
set -g base-index 1
setw -g pane-base-index 1
set -g renumber-windows on
set -g history-limit 50000
set -sg escape-time 10
set -g focus-events on
set -g set-clipboard on

# friendlier splits that keep the current path
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"

# reload
bind r source-file ~/.tmux.conf \; display "reloaded"

# readable status line
set -g status-style "bg=#1f2430,fg=#c8d3f5"
set -g window-status-current-style "bg=#2a3040,fg=#9ece6a,bold"

The daily loop

tmux new -A -s work -c ~/code/myproject
# work… then detach with  Ctrl+b d

tmux ls
tmux attach -t work

new -A means attach-or-create, so the same command is safe to run every time.

From the phone

ssh you@devbox
# or, over a tailnet:
mosh devbox -- \
  tmux new -A -s work

tmux keeps the process alive when the phone drops. mosh keeps the link alive when the network changes. Use both.

Agent host pattern

# one session per repo, nothing attached
tmux new -d -s work -c ~/code/myproject 'claude --continue'
tmux capture-pane -pt work | tail -20   # peek without attaching
tmux kill-session -t work

capture-pane -p is how you check on an agent from a script or a notification hook.

Prefix

Firefox reserves Ctrl+b for the bookmarks sidebar and may swallow it. If the prefix doesn’t arm, pick Ctrl+a or tap the prefix chip.
